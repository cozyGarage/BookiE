# Open proposals

Proposals record designs that have not become accepted decisions. They do not set release scope. Accepted constraints live in [ADRs](../decisions/README.md); selected work and status live in [Project #3](https://github.com/users/cozyGarage/projects/3) and the linked issues. Recheck each linked issue and source before acting.

| Proposal | Current boundary |
|---|---|
| [Local dependency patches](dependency-patches.md) | Local behavior and removal criteria; verify released dependency behavior before changing vendored code. |

Use the current [validation playbook](../validation-playbook.md) for test tiers and commands.
