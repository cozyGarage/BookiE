## Current peer comparison

This is a source-level comparison, not a ranking. New features in peer main branches may not be in their latest stable release. Feature names do not establish equivalent behavior or safety contracts.

| Peer | Current source and release | Comparison with BookiE |
|---|---|---|
| TablePro | Linux-capable `main` at `0f74142e` (October 26); stable `0.83.0` | Adds Search Database, Compare Results and repeatable Generate Rows. BookiE has no cross-table value search, result-set comparison or test-row generator. Current main also consolidates its grid and updates large-catalog sidebar behavior. BookiE already has DuckDB and MongoDB, bounded paste into loaded cells, and ambiguous-write guards. TablePro is distinct from TablePlus. |
| dbx | `main` at `6eac6d93` (October 26); stable `0.6.55` | Stable adds schema comparison options, trigger management for selected engines, generated values during import and queued exports. Main adds ordered local SQL file includes; BookiE has no file-include execution path. BookiE browses triggers without state mutation and has no schema/data comparison workflow. It supports **Filter by This Value** and structured **is none of** filtering; this does not establish parity with dbx's SQL-result filtering. |
| DBeaver Community | `devel` at `a79062e5` (October 26); stable `26.2.3` | Stable runs SQL files without opening them and offers a metadata-refresh notification after DDL. BookiE opens SQL files in the editor and already refreshes metadata after successful DDL. Development source adds dragging result cells into the editor as SQL literals; BookiE already has Copy as IN and INSERT but no drag-to-editor action. |
| Beekeeper Studio | `master` at `84df8c7c` (October 26); stable `6.1.6`, beta `6.2.0-beta.3` | Its new `not in` quick filter has operator parity with BookiE's structured **is none of** filter. A one-step Exclude Value action from the cell context menu was not identified in BookiE. |
| dbflux | `main` at `9ed2818d` (October 25); stable `0.8.13` | Stable includes TLS, input-validation and MySQL/MariaDB metadata fixes. Current main adds custom AWS Secrets Manager and SSM value-source endpoints. These are review prompts; they do not establish a matching BookiE defect. |
| TablePlus | No public source pin; official [Mac changelog](https://tableplus.com/blog/2017/02/changelogs.html) lists `27.1.0` (October 20), and [Linux changelog](https://tableplus.com/blog/2020/01/changelogs-linux.html) lists `1.7.0` (August 22) | Release notes are broad and do not support a feature-level comparison in this refresh. This is a separate product from TablePro. |
| Other eight peers | dbui `0.5.1`; dbdelve `0.5.1`; pgui `0.1.23`; NavOp `0.21.2`; fluxDB `0.1.12`; Based `2026.10.1`; pgAdmin `9.18`; DB Browser for SQLite `3.13.1` stable (newer nightly listed) | Current source and release freshness is pinned in the manifest. These entries were not feature-audited here; no BookiE parity or gap is inferred from version numbers alone. |

BookiE's product boundary remains a native Linux GTK client with static workspace drivers and one PolicyGuard path for GUI, MCP and `bookie-agentd`. It preserves typed values, explicit uncertain outcomes and local operation without an account or hosted service. Peer coverage can inform candidates, while BookiE's safety and value contracts remain the governing constraints. See the [October 26 review](archive/database-client-review-2026-10-26.md) for source pins, specific comparisons and evidence limits.

### Explicitly out of scope unless product goals change

Do not create BookiE work for Apple-only services and clients, license-gated
features, Sparkle or AppleScript, or an in-app AI client. BookiE's governed MCP
server is the chosen agent interface. Plugin-engine expansion, pairing deep
links and iCloud-synced icons are also excluded. Reconsider loadable SQLite
extensions only through an explicit security decision.

## Selection rule

Additional unselected candidates from the [October 18 audit](archive/code-and-ui-audit-2026-10-18.md#peer-fixes-and-ux-ideas) are dialect-specific type completion and responsive overflow for crowded toolbars. Custom pending-state accessibility and high-contrast review belong with DOC-3/#561; search and statement-band responsiveness need measurement before selecting a fix. The report contains source evidence, proposed order and acceptance, not a new delivery queue.

The comparison is the candidate inventory. The backlog contains selected
post-release work with an owner, acceptance layer and issue link. The
[0.2.0 scope](bookie-0.2-sprint.md#delivery-boundary) and [completion page](bookie-0.2-sprint.md)
record that release's boundary and status. When an item is selected, move its
concise statement into the backlog and create or link its issue; remove it from
this candidate section only when it is scheduled, accepted out of scope, or
implemented with evidence.
