Tracks [#1823](https://github.com/cozyGarage/BookiE/issues/1823). Linux base: `52813e341fed3c000c0872915a29e785e2a9da69`.

The dangling-policy unit regression failed before the fix. Two installed regressions also failed on the earlier fixture-installed executable: a dangling policy link and a malformed policy both allowed the saved SQLite connection to become ready instead of showing the required refusal. The dangling-link run also logged MCP startup. The executable contained the workspace-save changes from #1829; those changes do not alter the policy path.

Startup now stores no loaded policy on a configuration error. Candidate guard creation returns an error, and active guarded-handle lookup returns no handle until a policy loads successfully. Defaults remain available for a genuinely absent path. Ancestor inspection prevents a broken parent link from being mistaken for an absent configuration. A failed reload preserves a previously loaded policy; a successful reload recovers availability. Policy and driver rules are unchanged.

Full preflight passed: 2,228 unit tests, 292 sandbox tests and isolated Redis cancellation. Strict app Clippy passed. No termination cause was found in the inspected journal interval. [#1831](https://github.com/cozyGarage/BookiE/issues/1831) tracks the missing fixture diagnostics and unresolved cause. All 191 registered widget cases passed in the complete fresh-display run with captured Xvfb stderr. The previously failing clipboard case passed.
