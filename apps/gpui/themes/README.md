# Bundled colour themes

These theme files use the gpui-component theme format and come from BarSQL (GPL-3.0, https://github.com/Bare7a/BarSQL, commit `6575b6a`, `crates/barsql-ui/themes/`). Each palette's own licence sits next to its file (`*-LICENSE.txt`). BookiE is AGPL-3.0-or-later; GPLv3 section 13 allows combining the GPLv3 files with it.
